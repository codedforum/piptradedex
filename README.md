# PipTradeDex

PipTradeDex is a trading app that is private by default. It is powered by NEAR Confidential Intents and has reached its first 100 users.

- App: https://piptradedex.xyz
- X: https://x.com/PipTradeDex

## Highlights

- **Private by default.** Trades use NEAR Confidential Intents, so activity is not exposed by default.
- **One app.** Trade from a single interface instead of juggling separate tools.
- **Growing.** The first 100 users are on board.

Live. This repository holds the public project description only. The application source is closed.
